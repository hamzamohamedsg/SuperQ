# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SuperQ, please do not open a public issue.

Instead, please report it privately via GitHub Security Advisories or by emailing the maintainers directly.

You should receive an acknowledgment within 48 hours with details on next steps, triage, and a timeline for a patch.
